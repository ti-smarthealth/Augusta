# docs

Reference material that is not tied to one package.

| Folder | Contents |
| --- | --- |
| [`architecture/`](architecture/) | Current- and target-state AWS architecture diagrams, and the generator that produces them |
| [`product/`](product/) | What the product *is*, in two versions — as built, and with every plan implemented |

The two folders answer different questions about the same two states, and are
worth reading together: `architecture/` is what is deployed, `product/` is what
it does for whom.

Plans and runbooks stay at the repository root: `TELEMETRY.md`, `MIGRATION.md`,
`PLAN.md`, `REBUILD.md`, `HANDOFF.md`.
